Starshore v1.0.0

Rilis pertama: pembersih sampah dan pemampas video.

- Kamu yang memilih file mana yang dihapus, tidak ada penghapusan otomatis.
- Duplikat dicocokkan dari isi file, dan satu file asli tiap grup selalu tersisa.
- Kompres memakai encoder hardware, jadi cepat dan APK tetap kecil.
- Tidak ada izin internet, tidak ada iklan, tidak ada data yang keluar dari perangkat.

Peringatan: penghapusan permanen tanpa tempat sampah. Periksa daftarnya dulu.
Sisa folder aplikasi yang sudah dihapus, cache internal, dan log sistem butuh Shizuku atau root.
APK ditandatangani dengan debug key, jadi dipasang lewat "unknown sources". Android 7 ke atas.
