# CHANGES - Starshore
## v1.0.0 (rilis pertama)

- Pindai semua file di penyimpanan, tampilkan daftar dan ukurannya, lalu kamu yang memilih
  mana yang mau dihapus.
- File duplikat dicocokkan dari isi file; satu file asli tiap grup selalu tersisa.
- Bersihkan file sementara, log, cache, APK sisa, folder kosong, dan sampah galeri.
- Kompres video dengan encoder hardware, bisa pilih bitrate atau target ukuran per video.
- Audio mic, audio internal, atau keduanya, digabung ke hasil kompres.
- Bandingkan dua video dengan geser, plus pratinjau 5 detik sebelum kompres.
- 8 tema, latar belakang sendiri, getar dan bunyi tombol yang bisa dimatikan.
- Tombol Batal menghapus kata terakhir, tekan lagi untuk satu kata sebelumnya.
- 20 cuplikan terakhir bisa ditempel dari baris saran.
- Sisa aplikasi yang sudah dihapus, cache internal, dan log sistem bila Shizuku atau root aktif.
- Tidak ada izin internet, tidak ada iklan, tidak ada data yang keluar dari perangkat.
